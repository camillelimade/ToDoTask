# To Do Task
Esse repositório diz respeito a um sistema desenvolvido em prol do gereciamento de tarefas de maneira digital e dinamica

---
## Conceitos de POO implementados
- Classes
- Atributos
- Métodos
- Construtores
- Encapsulamento
---

## Estrutura de pacotes
- **app**: diz respeito a execução do sistema, esse diretório comporta a classe `Main`, que irá viabilizar as funcionalidades para o usuário.
- **controller**: representa a parte lógica do sistema, contendo as principais funcionalidades executadas em `app`
- **model**: contém os 'modelos'de entidades do sistema, como a classe `usuario`, e `tasks` que virão a ser instanciadas constantemente

## Funcionalidades
- Criar task
- Completar task
- Editar task
- Excluir task
- Listar tasks
